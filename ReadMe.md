# Ned Kelly on Planet TerraNulies

A **Unity game project** featuring Ned Kelly exploring the mysterious world of *Planet TerraNulies*.

> This is a **prototype / proof of concept** — several features and assets are placeholders and not representative of final gameplay.


## Overview

**Ned Kelly on Planet TerraNulies** is an experimental Unity project where players can move, shoot, and interact with the environment. The current build includes:

- A **prototype menu screen** (non-functional, for concept demonstration only)
- **Basic player movement and combat controls**
- A **sandbox-style level** where players can pick up weapons and engage with enemies


## Getting Started

### Requirements
- **Unity Hub** (latest version recommended)
- **Unity Editor** (compatible with your project version)

### Opening the Project
1. Clone or download this repository.
2. Open **Unity Hub**.
3. Click **Add Project from Disk** and select the downloaded folder.
4. Launch the project in Unity.


## Running the Game

> **Note:** The title screen is a placeholder and may not load gameplay correctly.

To play:
1. **Do not run through the title screen.** Instead, open the desired **scene** directly from the Unity **Assets** folder.
2. From the **Title Screen** asset, you can:
   - Select **Play** to load Level 1
   - Or choose another level from the **Level Select** screen

### Levels
Most levels currently contain:
- Minimal or no story progression
- Limited interactive objects
- Basic combat and environmental interaction
