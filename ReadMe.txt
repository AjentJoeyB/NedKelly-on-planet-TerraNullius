This is a Unity game, therefore it must be opened and launched using unity hub.

Ned Kelly on planet TerraNulies
the menu is a proof of concept and not a fully working menu screen with filler buttons and filler assets
notes to run tha game dont go through title screen just load the via unitya assets folder
Once the game is launched from the title screen asset, you can select play for level 1 or select another level from level select screen.
most of the levels include no story playthrough or objects, but the player can interact with environment by pickup weapons and shooting enemies.
W, A,S,D, space bar and shift are for basic movement, jumping and sprinting. Tab to select gun, while R is to reload. Left click to shoot and right click to aim.
